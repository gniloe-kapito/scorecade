# Scorecade — фронтенд (GitHub Pages)

Статический сайт Scorecade. Загружается в репозиторий GitHub и публикуется
на GitHub Pages через GitHub Actions. Все данные сайт берёт из бэкенда
(папка `backend/` — деплой на Cloudflare Workers).

## Как опубликовать (кратко)

Полная пошаговая инструкция — в `README.md` в корне папки `release/`.
Коротко:

1. Сначала разверните бэкенд (папка `backend/`) и получите адрес воркера.
2. Впишите адрес воркера в `public/config.js` (файл можно править прямо
   на GitHub после загрузки).
3. Загрузите содержимое ЭТОЙ папки в репозиторий GitHub.
4. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.

## Что здесь что

| Файл / папка | Назначение |
|---|---|
| `public/config.js` | **Адрес бэкенда** — единственный файл, который нужно править |
| `.github/workflows/pages.yml` | Автосборка и публикация при каждом push в `main` |
| `src/` | Код интерфейса (без какого-либо серверного кода) |
| `next.config.ts` | Статическая сборка (`output: "export"`), базовый путь подставляется автоматически из имени репозитория |

## Локальный запуск (не обязательно)

Нужен [Node.js](https://nodejs.org) (версия 20 или новее):

```bash
npm install        # установить зависимости (один раз)
npm run dev        # запустить сайт на http://localhost:3000
```

Адрес бэкенда берётся из `public/config.js` — при локальном запуске
впишите туда `http://localhost:8787` (если бэкенд запущен локально,
см. README бэкенда), а перед загрузкой на GitHub — адрес вашего воркера.

## Сборка вручную (не обязательно)

GitHub Actions делает это сам, но при желании можно собрать статический
сайт локально:

```bash
npm install
npm run build
```

Готовый сайт появится в папке `out/` (файл `index.html`).
